# ChatGPT/Codex 桌面适配

这里实现 OpenAI Codex 桌面端的选择器、CSS、原生主题映射和页面内 overlay，工作区包名为 @woodfish/chatgpt-app。

- 构建：pnpm --filter @woodfish/chatgpt-app run compile。
- 测试：pnpm --filter @woodfish/chatgpt-app run test --runInBand。
- 产物：TypeScript 文件输出到 apps/chatgpt-app/out；CLI 的 Codex bundle 输出到 apps/cli/assets。
