# Woodfish 预览样例

这些文件用于在沙盒 IDE 里检查渐变与发光效果（`./gradlew runIde` 会自动打开本目录）。

## 检查要点

- **渐变**：关键字、字符串、函数名等每个 token 都以自己的颜色为中点，从左到右过渡。
- **发光**：文字下方有柔和的同色光晕，浅色主题明显减弱。
- **中文与表情**：`中文注释` 这类需要回退字体的文字同样有渐变与发光（设置里可单独关闭），表情符号保持原样；两者都不出现重影。
- **连字**：`->`、`!=`、`=>` 在开启连字时仍是一个字形。

## 字符网格

2026.2 起，Markdown 文档同时含全角字符与表格时，编辑器会把每个字挪进等宽网格（中文占两格）。
下面这张表用于检查这种情况下中英文混排的文字仍与编辑器画的字重合。

| 效果 | 说明 | 默认 |
|:---|:---|:---:|
| 渐变 gradient | 每个 token 以自己的颜色为中点过渡 | 开 |
| 发光 glow | 文字下方的同色光晕 | 开 |
| 中日韩 CJK | 回退字体的文字也加效果 | 开 |
