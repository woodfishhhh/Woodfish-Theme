# 遇到问题

- **VS Code 更新后效果消失**：运行 **修复 Woodfish 注入**。
- **提示没有写入权限**：macOS 上如果是在终端里用 `code .`、`cursor .` 启动的，改从程序坞打开再试；其余情况按提示处理（macOS 需放进“应用程序”并在“App 管理”中允许；Windows 系统级安装需管理员运行一次；Linux Snap/Flatpak 版本不支持）。
- **提示“安装似乎损坏”**：开启、修改或移除效果后，在完全退出 VS Code 之前会一直出现，重新加载窗口不会消失。完全退出再打开即可。
- **Remote SSH / WSL / 容器**：Woodfish 会在本地界面运行，远程窗口同样有效。
- **想恢复原样**：运行 **彻底停用 Woodfish 叠层**，或直接卸载扩展（卸载会自动还原所有修改）。
- **提交 issue**：运行 **生成 Woodfish 诊断信息**，内容已复制到剪贴板，粘贴到 issue 即可。
